# Portfolio page + QR setup

This responsive page displays the supplied portfolio image with a subtle fade-in and slow zoom. It respects the visitor's reduced-motion accessibility setting.

## Finish uploading the image
The page expects the image at `assets/portfolio.png`. Create an `assets` folder in this repository and upload your original image as `portfolio.png`.

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the deployment to complete.
5. The expected URL is `https://gudla0098-arch.github.io/Detail/`.
6. Test the URL in a private/incognito browser window.

## QR code
Generate the final QR only after the public URL works. The QR should point to the webpage URL, not directly to the PNG.
